## Getting Started (Windows Setup)

Follow these steps to set up the project locally on Windows using Git:

### Prerequisites

Ensure you have **Git** installed on your system. You can download it from [git-scm.com](https://git-scm.com/).

### Installation & Local Setup

1. **Open Terminal**  
   Press `Win + R`, type `cmd` (or `powershell`), and hit **Enter**. Alternatively, right-click inside your target folder and select **Git Bash Here**.

2. **Clone the Repository**  
   Run the following command in your terminal to clone the repository to your machine:
